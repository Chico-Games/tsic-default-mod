Mod-shipped UI fonts - third-party notices
==========================================

These TrueType files are imported at runtime by the mod manager (every
`fonts/<Name>.ttf` becomes the UFont `/ModData/<mod>/fonts/<Name>`) and are
named from the UI theme as `mod:fonts/<Name>` (no extension). The native UI
falls back to the matching `/Game/UI/TSICMag/Fonts/F_*` asset when a file here
is missing.
